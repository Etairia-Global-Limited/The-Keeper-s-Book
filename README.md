# The-Keeper-s-Book

The-Keeper-s-Book is a faith-filled, people-first admin portal built to keep your digital house standing on solid rock and in apple-pie order. It is designed to help teams stay organized, accountable, and confident in the way they manage people, access, records, and operations.

Think of it as the calm in the middle of the storm: a sanctuary where applications, users, roles, clients, and important records are handled with clarity, stewardship, and a little divine order.

## What this app does

This application helps teams keep their house in order by managing:

- The Entire Flock — complete user management and profile oversight.
- The Book of Life — secure storage and maintenance of application and client records.
- The Straight & Narrow — user access mapping and role assignments.
- The Tabernacle Keys — tight, role-based permission control.
- The Judgment Seat — guided KYC review workflows.
- The Recording Angels — full audit history and activity tracking.
- The Watchtower — a dashboard that gives a quick pulse on what is happening.

In plain English: it helps the right people gain access to the right things while keeping bad actors at arm’s length and keeping records clear, traceable, and tidy from start to finish.

## Why it matters

When information is scattered, things get messy faster than a Sunday morning rush. The-Keeper-s-Book brings the essentials into one place so teams can move with confidence, stay accountable, and keep operations running like a well-oiled machine.

It is built for environments where trust matters, records are sacred, and no one wants to be left guessing who did what and when.

## Core features

- The Watchtower Overview — dashboard metrics and recent activity.
- The Sanctuary Registry — create, review, and edit user profiles with ease.
- The Book of Deeds — manage applications and systems in one place.
- The Ordination Panel — control application-user and application-role mappings.
- The Judgment Seat (KYC) — user verification and review flows.
- The Recording Angel Log — complete audit trails and accountability tracking.
- The Pearly Gates (Secure Login) — secure login and role-aware access control.

## Tech stack

This project is powered by:

- Angular 21
- TypeScript
- RxJS
- Express
- JWT authentication
- Vitest

## Getting started

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm start
```

Then open: http://localhost:4200/

### Build for production

```bash
npm run build
```

### Run tests

```bash
npm test
```

### Development server

```bash
ng serve
```

Once the server is running, open your browser and navigate to http://localhost:4200/. The application will automatically refresh whenever you modify source files.

### Code scaffolding

```bash
ng generate component component-name
```

For a full list of available schematics, run:

```bash
ng generate --help
```
